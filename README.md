# ATELIER COFFEE — Премиальная кофейня & Спешелти кофе

Современный адаптивный full-stack веб-сайт премиальной кофейни в стиле **premium minimalism** для портфолио веб-разработчика.

---

## ☕ О проекте

- **Бренд**: ATELIER COFFEE
- **Стилистика**: Премиальный минимализм, чистые формы, благородные натуральные оттенки (`#F6F2EA`, `#30251F`, `#D8C6AE`, `#FFFFFF`), элегантная акцидентная типографика (Cormorant Garamond) и читаемый гротеск (Plus Jakarta Sans).
- **Цены**: Казахстанский тенге (₸).
- **Особенности**: Полноценный каталог позиций, интерактивная корзина с сохранением в `localStorage`, оформление доставки и самовывоза с серверной валидацией, генерация уникального номера заказа (`ATL-YYMMDD-XXXX`), защищённая панель администратора с управлением статусами заказов и CRUD товаров.

---

## 🛠 Стек технологий

- **Фронтенд**: React 19, TypeScript, Vite 8
- **Стилизация**: Tailwind CSS v4, кастомная премиальная дизайн-система
- **Иконки**: Lucide React
- **Маршрутизация**: React Router v7
- **База данных & Auth**: Supabase (PostgreSQL, Row Level Security, RPC/функции)
- **Устойчивость**: Двухрежимная работа (Supabase + автономный fallback/demo mode). Сайт мгновенно запускается и полноценно функционирует даже без первичной настройки ключей API.

---

## 📂 Структура страниц

1. **Главная (`/`)**
   - Первый экран с атмосферной визуализацией и слоганом *«Кофе. Вкус момента.»*
   - Кнопки быстрого перехода *«Наше меню»* и *«Заказать кофе»*
   - Блок популярных напитков и десертов («Селекция месяца / Выбор шефа»)
   - Раздел философии и истории обжарки спешелти зерна на ростере Loring
   - Преимущества заведения (зерно 85+ SCA, крафтовая пекарня, экспресс-заказ)
   - Контакты, адрес (г. Алматы, пр. Достык, 105), график работы и элегантный футер.

2. **Меню (`/menu`)**
   - Категории: *Кофе*, *Чай*, *Холодные напитки*, *Десерты*.
   - Интерактивный живой поиск по названию и описанию.
   - 14 реалистичных позиций с фото, граммовками/объёмами, ценами и бейджами наличия.
   - Добавление в корзину с всплывающими toast-уведомлениями.

3. **Корзина (`/cart`)**
   - Управление количеством товаров (`+` / `-`).
   - Удаление отдельных позиций или полная очистка корзины.
   - Подсчёт промежуточной и итоговой суммы в ₸.
   - Автоматическое сохранение состояния между сессиями браузера.

4. **Оформление заказа (`/checkout`)**
   - Выбор способа получения: **Самовывоз** или **Доставка курьером**.
   - Поля: имя, телефон, адрес (при доставке), комментарий к заказу.
   - Валидация обязательных полей.
   - Сохранение заказа и защищённый экран подтверждения с номером заказа.

5. **Панель администратора (`/admin`)**
   - Экран безопасной авторизации (Supabase Auth + демо-доступ в 1 клик для ревью портфолио).
   - **Управление заказами**: просмотр состава, контактов, адреса, даты и смена статусов (*Новый*, *Подтверждён*, *Готовится*, *Готов*, *Завершён*, *Отменён*).
   - **Управление каталогом**: создание, редактирование позиций, изменение цен, картинок, описаний и тумблер наличия товара.

## 🚀 Быстрый запуск

### 1. Клонирование и установка зависимостей
```bash
git clone <url-вашего-репозитория>
cd site
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Сайт откроется по адресу `http://localhost:5173`.

### 3. Сборка для продакшна
```bash
npm run build
npm run preview
```

## 🗄 Настройка Supabase (опционально для боевого сервера)

1. Создайте проект на [supabase.com](https://supabase.com).
2. Перейдите в раздел **SQL Editor** и выполните скрипт миграции из файла:
   `supabase/migrations/20261012_init_schema.sql`
   Этот скрипт создаст:
   - Таблицы `products`, `orders`, `order_items`, `profiles`.
   - Серверный расчёт сумм и проверку ролей (`is_admin()`).
   - RLS-политики (публичный просмотр активных товаров, гостевые заказы, доступ к админке только для роли `admin`).
   - Начальные 14 позиций меню.
3. Скопируйте файл `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
4. Укажите ваши ключи в `.env`:
   ```env
   VITE_SUPABASE_URL=https://ваш-проект.supabase.co
   VITE_SUPABASE_ANON_KEY=ваш-публичный-ключ
   ```

> **Примечание для портфолио**: Если переменные окружения не заполнены, проект автоматически работает в автономном демонстрационном режиме с локальным сохранением и тестовым входом в админку:
> - **Email**: `admin@atelier.coffee`
> - **Пароль**: `atelier2026`
