# ATELIER COFFEE — Демонстрационный проект кофейни (Портфолио)

Современный адаптивный веб-сайт премиальной кофейни в стиле **premium minimalism**, созданный для публичной демонстрации в портфолио веб-разработчика и деплоя на **Vercel**.

> ⚠️ **Важное примечание:** Данный проект является интерактивным концептом и демонстрацией интерфейса для портфолио. Это не настоящий интернет-магазин: реальные платежи не принимаются, товары не доставляются. Все данные изолированно сохраняются в локальном хранилище браузера (`localStorage`).

---

## ✨ Особенности проекта

- **Премиальный минималистичный дизайн**: гармоничная тёплая палитра (`#F6F2EA`, `#30251F`, `#D8C6AE`), выверенная типографика (*Cormorant Garamond* + *Plus Jakarta Sans*), просторные композиции и адаптивность для всех типов экранов (Mobile, Tablet, Desktop).
- **Интерактивное меню**: 14 позиций спешелти кофе, чая и авторских десертов в тенге (₸) с фильтрацией по категориям и живым поиском.
- **Локальная корзина**: добавление, изменение количества, расчёт итогов и всплывающие уведомления с сохранением состояния при перезагрузке страницы.
- **Демонстрация оформления заказа (`/checkout`)**: интерактивная форма (выбор самовывоза или доставки, адрес, контакты, комментарий) с явным указанием демонстрационного характера и генерацией номера заказа (`ATL-YYMMDD-XXXX`).
- **Безопасная демо-консоль управления (`/admin`)**: интерактивная панель для ревью портфолио без бэкенда и паролей, где можно протестировать изменение статусов заказов, добавление и редактирование блюд в локальном каталоге.

---

## 🛠 Технологический стек

- **Фреймворк**: React 19 + TypeScript
- **Сборщик**: Vite 8
- **Стилизация**: Tailwind CSS v4
- **Иконки**: Lucide React
- **Маршрутизация**: React Router v7
- **Хранение данных**: LocalStorage (полностью автономная клиентская работа без внешних серверов)

## 🚀 Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd site
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу `http://localhost:5173`.

4. Проверка production-сборки:
   ```bash
   npm run build
   npm run preview
   ```

## ☁️ Деплой на Vercel

Проект полностью оптимизирован для мгновенного развёртывания на платформе **Vercel**:

1. Загрузите код в ваш репозиторий GitHub/GitLab.
2. В панели [Vercel](https://vercel.com/) нажмите **Add New -> Project** и импортируйте репозиторий.
3. Настройки проекта (определяются автоматически):
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Никаких переменных окружения (`Environment Variables`) указывать не требуется.
5. В корне проекта уже настроен файл `vercel.json` с SPA-rewrites, поэтому прямые переходы по ссылкам (`/menu`, `/cart`, `/checkout`, `/admin`) будут работать без ошибок 404.
6. Нажмите **Deploy**.

## 🧭 Демонстрационная функциональность (Что эмулируется в браузере)

| Функция | Как реализовано в демо |
|---|---|
| Каталог меню | Загружается из локального набора данных с возможностью поиска и фильтрации. |
| Корзина | Работает автономно в `localStorage` вашего браузера. |
| Оформление заказа | Форма валидирует данные и создает тестовый номер заказа без обращения к платёжным шлюзам. |
| Панель управления (`/admin`) | Открыта для тестирования заказчиком/работодателем, изменения сохраняются локально и сбрасываются кнопкой «Сбросить каталог». |
